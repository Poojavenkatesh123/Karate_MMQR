# Karate BDD Framework Project

## Project Structure

- `src/test/java` - Java test runners and utility classes
- `src/test/resources/features` - Karate feature files
- `src/test/resources/data` - Test data files
- `src/test/resources/config` - Configuration files

## Getting Started

1. Ensure you have Java and Maven installed.
2. Run tests with:
   ```sh
   mvn test
   ```

## Dependencies
- [Karate JUnit5](https://github.com/karatelabs/karate)

---

This project is set up for BDD API testing using Karate.
